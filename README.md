# PIXEL RIFT

Android portrait brick-breaking game prototype. First playable map: **DESERT GATE**, 2,300 breakable pixels, time/loss counters, English-only UI.

**Scope:** offline-first prototype. Firebase, global ranking, real ads and paid purchasing are deferred by the owner. Shop and leaderboard show non-live placeholders only.

GitHub Actions builds an Android debug APK from Flutter/Flame source and attaches it as a workflow artifact. Do not describe a build as complete until its Actions job succeeds.

## v0.3 reference style gameplay
T-shaped corridor, 2300 orange bricks, 12 multiball pickups, faster 300-ball swarm, and original crisp arcade impacts. Firebase remains postponed.
